TEST API THIET YEU - WebBanA.I
Base URL: http://localhost:3000

Chay server:
npm start

Header chung khi gui body JSON:
Content-Type: application/json

API nao can xac thuc thi them header:
Authorization: Bearer <token>

Lay token bang API dang nhap. Login user thi lay user_token. Login admin thi lay admin_token.

Tai khoan test co san:
Admin: admin / 11111111
User: user1 / 11111111

============================================================
1. DANG NHAP - lay token
============================================================

POST http://localhost:3000/api/auth/login
Khong can Authorization

Body admin:
{
  "username": "admin",
  "password": "11111111"
}

Body user:
{
  "username": "user1",
  "password": "11111111"
}

Ket qua tra ve co token:
{
  "token": "...",
  "user": {}
}

============================================================
2. XEM SAN PHAM
============================================================

GET http://localhost:3000/api/products
Khong can Authorization

Tim kiem:
GET http://localhost:3000/api/products?q=chatgpt
Khong can Authorization

============================================================
3. KIEM TRA TOKEN DANG NHAP
============================================================

GET http://localhost:3000/api/auth/me

4. TAO DON HANG
============================================================

{

  "phone": "0901234567",
  "email": "test@gmail.com",
  "paymentMethod": "bank_transfer",

============================================================
10. ADMIN TRAIN AI BANG FILE
============================================================

POST http://localhost:3000/api/ai-knowledge
Can Authorization admin:
Authorization: Bearer <admin_token>

Body:
{
  "fileName": "faq.txt",
  "mimeType": "text/plain",
  "mode": "append",
  "contentBase64": "RkFRCnNob3AgY28gdXkgdGluIGtob25nPwpTaG9wIGNhbSBrZXQgdXkgdGluLg=="
}

Ghi chu:
- mode = append de them knowledge.
- mode = replace de xoa knowledge cu va thay bang file moi.
- Ho tro JSON, TXT, SQL, CSV, DOCX, XLSX va cac file text pho bien.
- Neu gui JSON truc tiep van duoc:
{
  "fileName": "faq.json",
  "mode": "append",
  "data": {
    "conversation": {
      "customer_query": "Shop co uy tin khong?",
      "shop_response": "Shop cam ket uy tin va ho tro hau mai."
    }
  }
}
